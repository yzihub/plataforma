# Archived Workflows

Archived workflows are retained for audit, rollback reconstruction, and
forensic comparison only.

Do not publish archived workflows directly.

## Subdirectories

- `snapshots`: raw n8n exports and workflow list snapshots.
- `pre-runtime`: intermediate hardening outputs and ID-named duplicates.
- `legacy`: old contract/workflow exports and pre-canonical artifacts.
- `experiments`: non-production experiments.
