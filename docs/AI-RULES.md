## REGRAS GERAIS

* Sempre usar os arquivos da pasta /docs como fonte da verdade
* Nunca inventar dados ou campos
* Seguir arquitetura definida em architecture.md
* Seguir padrões de UI em ui-patterns.md
* Seguir estrutura de dados em data-mapping.md
