# 🎨 YZIHUB - UI Patterns

## 🧩 Design System Base

### COMPONENTES CORE

* alert → feedback
* avatar → usuário
* badge → status
* button → ações
* dropdown → menus
* modal → criação/edição
* table → dados principais
* images → mídia
* video → embed

---

## 📐 Padrões de Tela

### 🧾 Estrutura Base

1. Header

* título
* ação principal

2. Cards (opcional)

* métricas

3. Filtros

* busca
* dropdown

4. Conteúdo

* tabela ou kanban

---

## 📊 Tabelas

* Sempre usar `table`
* Colunas claras
* Sem células vazias
* Ações via dropdown

---

## 🏷️ Status (badge)

* verde → sucesso
* amarelo → atenção
* vermelho → crítico
* azul → informativo

---

## 🪟 Modais

* Criar / Editar
* Formulários claros
* Validação básica

---

## 🧠 UX Rules

* Sem espaços vazios
* Hierarquia clara
* Ação principal visível
* Feedback imediato

---

## 🎯 Layout

* Espaçamento consistente
* Visual clean (SaaS)
* Dark mode padrão
