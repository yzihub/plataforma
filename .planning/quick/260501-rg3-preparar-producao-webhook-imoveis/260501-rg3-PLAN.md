    3. **Gerar secret de producao**
       - REGRA: NUNCA reusar secret de dev. Producao precisa de secret novo.
       - Comando macOS/Linux: `openssl rand -hex 32`
       - Comando Windows PowerShell (equivalente):
         ```powershell
         -join ((1..64) | ForEach-Object { '{0:x}' -f (Get-Random -Max 16) })
         ```
         (Alternativa nativa: `[System.Convert]::ToHexString([System.Security.Cryptography.RandomNumberGenerator]::GetBytes(32))`)
       - Resultado esperado: string hexadecimal de 64 caracteres.
       - Salvar este valor em local seguro (gerenciador de senhas) — sera usado em DOIS lugares: Vercel e wp-config.php.

    4. **Configurar WEBHOOK_IMOVEIS_SECRET na Vercel**
       Documentar AS DUAS formas (UI e CLI):

       **Opcao A — Dashboard (UI):**
       1. Acessar https://vercel.com/dashboard e abrir o projeto.
       2. Settings > Environment Variables.
       3. Add New:
          - Name: `WEBHOOK_IMOVEIS_SECRET`
          - Value: (colar o secret gerado)
          - Environment: marcar **Production** (e opcionalmente Preview)
       4. Save.
       5. Trigger redeploy: Deployments > ultimo deploy > Redeploy (sem cache).

       **Opcao B — CLI:**
       ```bash
       vercel env add WEBHOOK_IMOVEIS_SECRET production
       # cola o secret quando solicitado
       vercel --prod
       ```

       Observacao: a variavel NAO leva prefixo `NEXT_PUBLIC_` — ela e server-only e nunca deve aparecer no bundle do cliente.

    5. **Constante WordPress (wp-config.php)**
       Adicionar no wp-config.php do site WordPress (acima da linha `/* That's all, stop editing! */`):

       ```php
       define('YZIWS_WEBHOOK_SECRET', 'COLAR_AQUI_O_MESMO_SECRET_DA_VERCEL');
       define('YZIWS_WEBHOOK_URL', '<URL_DA_TASK_1>/api/webhook/imoveis');
       ```
