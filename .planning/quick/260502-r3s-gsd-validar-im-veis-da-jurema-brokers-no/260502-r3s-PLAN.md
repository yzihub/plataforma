Passo 1 — Contagem total no Supabase para o tenant Jurema:

Use o Supabase MCP (`mcp__supabase__execute_sql`) com a query abaixo. Project ID: descobrir via `mcp__supabase__list_projects` (procure pelo project com URL `dwmbklfkrtumfaxrbxio.supabase.co` — referência em CLAUDE.md seção 2).

Query A (total cru):
```sql
SELECT COUNT(*) AS total
FROM imoveis
WHERE tenant_id = '82cc7aa9-fc6e-4f37-8d8e-8a71c1691361';
```

Query B (filtros que o Cockpit aplica — espelha route.ts):
```sql
SELECT COUNT(*) AS visiveis_no_cockpit
FROM imoveis
WHERE tenant_id = '82cc7aa9-fc6e-4f37-8d8e-8a71c1691361'
  AND status_publicacao = 'Publicado'
  AND status_operacional = 'disponivel';
```

Query C (amostra de 10 imóveis para validar id_imovel pattern + códigos comerciais):
```sql
SELECT id_imovel,
       titulo_comercial,
       metadata->>'codigo_do_imovel' AS codigo_comercial,
       status_publicacao,
       status_operacional,
       (foto_principal IS NOT NULL OR imagem_card IS NOT NULL) AS tem_foto
FROM imoveis
WHERE tenant_id = '82cc7aa9-fc6e-4f37-8d8e-8a71c1691361'
ORDER BY updated_at DESC
LIMIT 10;
```

Query D (verificar duplicados de código comercial — não devem causar colapso, mas precisamos saber se existem):
```sql
SELECT COALESCE(metadata->>'codigo_do_imovel', id_imovel) AS codigo_efetivo,
       COUNT(*) AS ocorrencias
FROM imoveis
WHERE tenant_id = '82cc7aa9-fc6e-4f37-8d8e-8a71c1691361'
  AND status_publicacao = 'Publicado'
  AND status_operacional = 'disponivel'
GROUP BY codigo_efetivo
HAVING COUNT(*) > 1
ORDER BY ocorrencias DESC
LIMIT 20;
```

Query E (validar pattern wp-{id} em id_imovel):
```sql
SELECT
  COUNT(*) FILTER (WHERE id_imovel ~ '^wp-[0-9]+$') AS com_padrao_wp,
  COUNT(*) FILTER (WHERE id_imovel IS NOT NULL AND id_imovel !~ '^wp-[0-9]+$') AS fora_do_padrao,
  COUNT(*) FILTER (WHERE id_imovel IS NULL) AS sem_id_imovel
FROM imoveis
WHERE tenant_id = '82cc7aa9-fc6e-4f37-8d8e-8a71c1691361';
```
