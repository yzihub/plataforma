1. Create `src/app/api/contracts/route.ts` following exact pattern from leads API:
   - **GET**: Auth user -> get tenant_id from profiles -> `supabase.from('contracts').select('*').eq('tenant_id', tenantId).order('updated_at', { ascending: false })` -> return JSON array
   - **POST**: Auth user -> get tenant_id -> validate body (lead_name required, value required) -> `supabase.from('contracts').insert({ ...body, tenant_id: tenantId })` -> return 201 with created contract
   - Both handlers: try/catch, proper error responses (401, 400, 500)

2. Create `src/app/api/contracts/[id]/route.ts`:
   - **PATCH**: Auth user -> get tenant_id -> verify contract belongs to tenant -> accept partial update body with allowed fields: `status`, `notes`, `signed_at`, `file_url`, `file_name`, `title`, `type`, `value`, `expires_at`
     - If body contains `status === 'assinado'` and no `signed_at` provided, auto-set `signed_at = new Date().toISOString()`
     - `supabase.from('contracts').update(updateData).eq('id', contractId).eq('tenant_id', tenantId).select().single()`
     - Return updated contract
   - **POST** (for file upload): Auth user -> get tenant_id -> read FormData file -> validate file type (pdf, docx only, max 10MB) -> upload to Supabase Storage bucket `contracts` with path `{tenantId}/{contractId}/{filename}` -> get signed URL -> update contract row with `file_url` and `file_name` -> return updated contract
     - Use `supabase.storage.from('contracts').upload(filePath, fileBuffer, { contentType, upsert: true })`
     - Get public/signed URL: `supabase.storage.from('contracts').createSignedUrl(filePath, 3600)`
   - Both: same auth pattern as leads API (getUser -> profiles -> tenant_id)
