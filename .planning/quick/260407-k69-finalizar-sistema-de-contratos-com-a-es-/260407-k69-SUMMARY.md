# Phase quick Plan 260407-k69: Finalizar Sistema de Contratos com Acoes Summary

**One-liner:** Contracts module fully wired to Supabase with tenant-scoped RLS, CRUD API, file upload via Storage, and a functional drawer with edit notes / change status / mark signed / attach file actions.

## What Was Built

### Task 1 — Migration + Types

- `supabase/migrations/011_contracts_table.sql`: Full contracts table with `title`, `file_url`, `file_name`, `signed_at`, `expires_at`. Indexes on `tenant_id`, `lead_id`, `status`. `set_updated_at` trigger. RLS using existing `is_global_admin()` and `auth_tenant_id()` helpers.
- Supabase Storage bucket `contracts` created with tenant-folder scoped RLS policies (select, insert, update).
- Seed: 5 Jurema Brokers contracts using real lead UUIDs from migration 003. Mixed statuses: 1 assinado, 2 pendente, 1 rascunho, 1 cancelado.
- `src/types/contracts.ts`: Added `title?`, `file_url?`, `file_name?` fields to `Contract` interface.

### Task 2 — API Routes

- `GET /api/contracts`: Auth → tenant_id from profiles → `contracts.select(*).eq(tenant_id).order(updated_at desc)`
- `POST /api/contracts`: Validates `lead_name` and `value`, inserts with all fields, returns 201.
- `PATCH /api/contracts/[id]`: Allows updating 9 fields. Auto-sets `signed_at = now()` when `status === 'assinado'` and no signed_at provided. Verifies contract belongs to tenant before update.
- `POST /api/contracts/[id]`: Handles file upload. Validates MIME type (PDF/DOCX only) and size (max 10MB). Uploads to `contracts/{tenantId}/{contractId}/{filename}` in Supabase Storage. Returns signed URL (1h TTL). Updates contract row with `file_url` and `file_name`.

### Task 3 — Frontend

- `ContractDrawer.tsx` (new standalone file): Extracted from ContractsClient and upgraded with 4 functional actions:
  - **Edit notes**: Inline textarea toggle, saves via PATCH, shows success feedback toast
  - **Change status**: Select dropdown, PATCH on change, badge updates immediately via `onContractUpdated`
  - **Mark as signed**: Two-step confirm dialog, PATCH `{status: 'assinado'}`, button hidden when already assinado
  - **File upload**: Drag-style label input for PDF/DOCX, POST with FormData, shows download link after upload
- `ContractsClient.tsx` (rewritten): Removed `MOCK_CONTRACTS` import. `useContracts` hook now fetches from `/api/contracts` with `useEffect`. Added `createContract` (POST), `updateContractLocal` (optimistic), `refetch`. Error state with retry button. `handleCancelContract` wired from table.
- `NewContractModal.tsx` (updated): Fetches real leads/properties/corretores from Supabase on modal open. Added `title` field. Added optional file attachment (uploaded after contract created). `onSave` signature updated to `async (body) => Promise<Contract | null>`.
