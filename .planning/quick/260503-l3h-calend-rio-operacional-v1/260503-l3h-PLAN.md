<task type="auto" tdd="false">
  <name>Task 2: Criar API route GET/POST /api/appointments</name>
  <files>src/app/api/appointments/route.ts</files>
  <behavior>
    - GET sem query: retorna { ok: true, appointments: Appointment[] } ordenados por start_at asc, filtrados por tenant do user logado
    - GET com ?upcoming=true: retorna apenas appointments com start_at >= now()
    - POST com body NewAppointmentInput válido: cria registro, retorna { ok: true, appointment: Appointment }
    - POST sem campos obrigatórios (title, appointment_type, start_at): retorna 400 com { ok: false, error: string }
    - POST sem auth/tenant: retorna 401 com { ok: false, error: 'unauthorized' }
  </behavior>
  <action>
    Criar `src/app/api/appointments/route.ts` seguindo padrão de `src/app/api/imoveis/route.ts` e `src/app/api/contracts/route.ts`:

    1. Imports: NextRequest, NextResponse, createClient de @/lib/supabase/server, types de @/types/appointments
    2. Função utilitária interna `getCurrentTenantId(supabase)`:
       - Pega user via supabase.auth.getUser()
       - Se !user: retorna null
       - Busca profiles.tenant_id where id = user.id
       - Retorna tenant_id ou null
    3. `export async function GET(request: NextRequest)`:
       - createClient() (server)
       - tenantId = await getCurrentTenantId(supabase); se null → 401
       - upcoming = request.nextUrl.searchParams.get('upcoming') === 'true'
       - query = supabase.from('appointments').select('*').eq('tenant_id', tenantId).order('start_at', { ascending: true })
       - if (upcoming) query = query.gte('start_at', new Date().toISOString())
       - data, error = await query
       - if (error) return NextResponse.json({ ok: false, error: error.message }, { status: 500 })
       - return NextResponse.json({ ok: true, appointments: data ?? [] })
    4. `export async function POST(request: NextRequest)`:
       - createClient() (server)
       - tenantId = await getCurrentTenantId(supabase); se null → 401
       - body = await request.json()
       - Validar campos obrigatórios: title (string non-empty), appointment_type (membro do union), start_at (string ISO parseável)
       - Se inválido: 400 com mensagem clara
       - Whitelist de campos permitidos no insert: title, appointment_type, status, lead_id, broker_id, start_at, end_at, location, description
       - integration_provider e integration_status NÃO vêm do body — server seta integration_status='pendente' e integration_provider=null por default
       - Insert: supabase.from('appointments').insert({ tenant_id: tenantId, ...whitelistedFields }).select('*').single()
       - if (error) return 500 com error.message
       - return NextResponse.json({ ok: true, appointment: data }, { status: 201 })
    5. Não chamar n8n. Não usar service_role.

    Preserve padrões de código (tabs/spaces, error shape) usados em route.ts vizinhas.
  </action>
