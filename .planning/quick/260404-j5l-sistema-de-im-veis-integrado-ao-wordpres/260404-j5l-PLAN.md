  <files>supabase/migrations/010_properties_wordpress_sync.sql, src/types/properties.ts</files>
  <action>
1. Create `supabase/migrations/010_properties_wordpress_sync.sql`:
   - ALTER TABLE properties ADD COLUMN IF NOT EXISTS:
     - `external_id TEXT` — ID from WordPress or other external source
     - `source TEXT DEFAULT 'manual'` — origin identifier (e.g., 'wordpress', 'manual')
     - `description TEXT` — full property description
     - `images JSONB DEFAULT '[]'::jsonb` — array of image URLs from external source
     - `features JSONB DEFAULT '{}'::jsonb` — structured features (bedrooms, bathrooms, garage, etc.)
     - `score INTEGER DEFAULT 0` — internal scoring for prioritization
     - `priority TEXT DEFAULT 'normal' CHECK (priority IN ('low', 'normal', 'high', 'urgent'))`
     - `kanban_stage TEXT` — defaults to neighborhood value; used for board grouping
   - Add UNIQUE constraint: `CREATE UNIQUE INDEX IF NOT EXISTS idx_properties_external_source ON properties(external_id, source) WHERE external_id IS NOT NULL;`
   - Create upsert function `upsert_property_from_external(p_tenant_id UUID, p_external_id TEXT, p_source TEXT, p_title TEXT, p_price NUMERIC, p_neighborhood TEXT, p_status TEXT DEFAULT 'available', p_description TEXT DEFAULT NULL, p_images JSONB DEFAULT '[]', p_features JSONB DEFAULT '{}', p_location TEXT DEFAULT NULL, p_photo_url TEXT DEFAULT NULL, p_property_type TEXT DEFAULT NULL, p_area_sqm NUMERIC DEFAULT NULL, p_link TEXT DEFAULT NULL)` that:
     - Does INSERT ... ON CONFLICT (external_id, source) DO UPDATE
     - Sets kanban_stage = p_neighborhood when inserting new rows
     - Returns the upserted row
   - RLS already enabled from migration 008 — no changes needed.

2. Create `src/types/properties.ts`:
   - Move the Property interface OUT of PropertyCard.tsx into this file (the canonical location)
   - Extend it with new fields: `external_id`, `source`, `description`, `images`, `features`, `score`, `priority`, `kanban_stage`
   - Export `Property` type
   - Export `KANBAN_NEIGHBORHOODS` constant: `['Cabo Branco', 'Manaira', 'Bessa', 'Altiplano']` — these are the fixed columns; any property with a neighborhood not in this list goes to "Outros"
   - Export `PropertyKanbanStage` type = typeof KANBAN_NEIGHBORHOODS[number] | 'Outros'
   - Update PropertyCard.tsx import to use `from "@/types/properties"` instead of local interface (keep backward compat by re-exporting: `export type { Property } from "@/types/properties"`)
