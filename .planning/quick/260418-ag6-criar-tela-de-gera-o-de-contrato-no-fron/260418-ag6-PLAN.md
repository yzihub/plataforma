**Parte A — API route POST /api/contracts/generate:**

Criar src/app/api/contracts/generate/route.ts seguindo padrao de src/app/api/contracts/route.ts.

Logica:
1. Verificar autenticacao via supabase.auth.getUser()
2. Buscar tenant_id do profile (mesmo padrao do contracts/route.ts)
3. Ler body: { lead_id, modelo, comprador, vendedor, imovel, corretor, valor, forma_pagamento, comissao, observacoes, canais }
4. Validar: modelo obrigatorio (400 se ausente)
5. Inserir em job_queue:
```typescript
await supabase.from("job_queue").insert({
  tenant_id,
  action: "gerar_contrato",
  status: "pending",
  payload: {
    lead_id:         body.lead_id ?? null,
    modelo:          body.modelo,
    comprador:       body.comprador ?? null,
    vendedor:        body.vendedor ?? null,
    imovel:          body.imovel ?? null,
    corretor:        body.corretor ?? null,
    valor:           body.valor ? parseFloat(body.valor) : null,
    forma_pagamento: body.forma_pagamento ?? null,
    comissao:        body.comissao ? parseFloat(body.comissao) : null,
    observacoes:     body.observacoes ?? null,
    canais:          body.canais ?? { whatsapp: false, email: false },
  },
});
```
6. Retornar 200 { success: true, message: "Contrato em geracao" }
7. Em caso de erro: 500 com { error: "Erro ao enfileirar geracao de contrato" }
